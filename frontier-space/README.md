## What is operational

The Space serves a dependency-free Python runtime with:

- ten responsive, keyboard-accessible, reduced-motion-aware experience concepts;
- a machine-readable vertical catalog and per-vertical experience contract;
- a fail-closed proposal → policy → human binding → receipt evaluation API;
- deterministic append-only receipt verification;
- exact source-binding metadata;
- no public effectors and no automatic execution of public-data connectors.

## Runtime boundary

The runtime intentionally starts with **zero model adapters**, **zero external
kernel adapters**, and **zero effectors** bound. A Hugging Face repository does
not make a model or kernel live. Missing bindings are reported as
`UNAVAILABLE`; consequential requests remain `HOLD` or `DENY`.

Killinchu's public experience is synthetic and **SIMULATED_ONLY**. It provides
no live weapon command, targeting authority, or operational effect path.

Lambda is an advisory weighted-geometric signal. Lambda uniqueness remains
**Conjecture 1 — OPEN** and is never represented as proven trust.

## Data and code provenance

Public category products were studied for general problem-solving patterns, not
copied. No proprietary source code, private data, distinctive copy, trade dress,
or competitor visual assets are included. External code may enter the estate
only through a compatible open-source license and an exact revision record.
Official public data may enter only through a fixed, bounded connector contract.

## Verification

The protected publisher deploys the exact Dockerfile-derived closure, restarts
the Space, verifies every pushed byte, and checks the declared public routes
against the exact source revision.

A running Space, HTTP 200, polished interface, model card, or receipt does not
establish factual truth, safety, performance, compliance, adoption, funding,
revenue, or production authorization.
